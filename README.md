# 파크노트

파크골프 점수 기록 웹앱입니다. 설치 없이 휴대폰 브라우저에서 바로 씁니다. 상단 **홈 화면에 추가** 버튼: 크롬은 한 번 누르면 아이콘이 생기고, 삼성 인터넷·아이폰은 메뉴에서 바로가기를 만드는 방법을 그림으로 안내합니다. (삼성 인터넷에서 앱으로 설치하면 Google Play 프로텍트 경고가 떠서 바로가기 방식을 씁니다)

☕ 만든이: 커피향기

## 기능
- 홀별 빠른 입력: 가운데를 누르면 파, −/+로 조정, OB 표시
- 코스별 점수표: 버디 ○, 보기 □, 홀인원 금색 표시
- 순위: 공동 순위 또는 백카운트(마지막 코스 → 마지막 홀부터 역순 비교)
- 결과 사진 보내기: 합계표만 / 전체 점수표를 사진으로 만들어 카카오톡으로 보내기, 사진 복사·저장, 글자로 보내기
- 기록 저장, 저장한 기록도 언제든 사진으로 다시 보내기
- 조원과 점수 합치기: 각자 입력한 점수를 QR로 주고받아 한 휴대폰에 모으기(서로 다른 점수는 골라서 반영)
- 링크로 보내기: 점수표를 링크 하나로 카카오톡에 보내면, 앱 없는 사람도 눌러서 전체 점수표를 볼 수 있음(내 기록에 저장·이어서 입력 가능)
- 구장 날씨: 지금 날씨, 시간별 예보, 비·바람·자외선·기온차 안내, 구장 위치 저장, 주변 파크골프장 지도
- 핸디캡(선택): 켜면 이름 옆 핸디 칸, 경기가 끝나면 ‘실타수 − 핸디’로 순위, 기록 평균으로 핸디 추천
- 개인 통계(9홀 평균, 최고 기록, 추이 그래프), 구장별 코스·파 저장
- 만보기: 휴대폰 동작 센서로 걸음 측정(화면이 켜져 있는 동안), 직접 입력, 최근 7일 그래프
- 상단 날짜·시각, 큰 글씨, 밝은 화면 기본(어두운 화면은 달 아이콘으로 전환), 오프라인 사용

기록은 각 휴대폰 브라우저 안에만 저장됩니다.

## 배포 (GitHub Pages)
Settings → Pages → Branch `main` / `(root)` → Save.
파일을 고치면 `sw.js`의 `VERSION` 값을 올려야 사용자 휴대폰에 새 버전이 반영됩니다.
