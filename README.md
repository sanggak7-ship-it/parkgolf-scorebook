# 파크골프 스코어북

파크골프 점수 기록 웹앱입니다. 설치 없이 휴대폰 브라우저에서 바로 쓰고, 홈 화면에 추가하면 앱처럼 열립니다.

## 기능
- 홀별 빠른 입력: 가운데를 누르면 파, −/+로 조정, OB 표시
- 코스별 점수표: 버디 ○, 보기 □, 홀인원 금색 표시
- 순위: 공동 순위 또는 백카운트(마지막 코스 → 마지막 홀부터 역순 비교)
- 결과 공유: 텍스트(카카오톡 붙여넣기), 결과 이미지
- 기록 저장, 개인 통계(9홀 평균, 최고 기록, 추이 그래프), 구장별 코스·파 저장
- 만보기: 휴대폰 동작 센서로 걸음 측정(화면이 켜져 있는 동안), 직접 입력, 최근 7일 그래프
- 큰 글씨, 다크 모드, 오프라인 사용

데이터는 각 기기의 브라우저에만 저장됩니다.

## GitHub Pages로 배포
1. 저장소 **Settings → Pages**
2. **Source: Deploy from a branch**, **Branch: `main` / `(root)`** 선택 후 **Save**
3. 1~2분 뒤 `https://<사용자명>.github.io/parkgolf-scorebook/` 에서 열립니다.

파일을 고치면 `sw.js`의 `VERSION` 값을 올려야 사용자 기기에 새 버전이 반영됩니다.
